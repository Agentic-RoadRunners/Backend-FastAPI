SafeRoad LangGraph State Graph

Bu diyagram, Backend-FastAPI/agent/graph.py dosyasındaki LangGraph akışını gösterir: kullanıcı mesajı agent node'una gelir, LLM gerekirse tool çağırır, tools node'u sonucu üretir ve akış tekrar agent'a döner. Tool çağrısı kalmadığında ya da maksimum iterasyona ulaşıldığında akış END ile kapanır.

Graph Diagram

Nodes, edges, conditional routing, state

How to Read It

from graph.py

Node Meaning

  • START: `/chat` isteği graph'a girer.
  • agent: LLM karar verir, tool çağrısı üretir veya direkt cevap döner.
  • tools: LangGraph `ToolNode`, seçilen tool'u çalıştırır.
  • END: Akış tamamlanır ve son cevap döner.

Edge Meaning

START → agent: giriş noktası
agent → tools: model tool çağırdıysa
tools → agent: tool sonucu geri beslenir
agent → END: tool yoksa veya limit dolduysa

State Alanları

  • messages: konuşma geçmişi
  • highlight_ids: frontend'de vurgulanacak ID'ler
  • related_node_ids: ilişkili node'lar
  • tool_calls_made: debug / izlenebilirlik
  • iteration_count: döngü limiti kontrolü

Why It Matters

  • Doğal dili kontrollü bir karar akışına çevirir.
  • Tool kullanımını güvenli ve izlenebilir yapar.
  • Konuşma bağlamını aynı thread içinde taşır.
  • Sonsuz cevap üretme döngüsünü sınırlar.
